# Northstar Financial Services — Synthetic Data

This dataset is synthetic and contains no real customer information.

Purpose:
- Demonstrate Business Analysis data investigation.
- Support SQL, Excel and Power BI analysis for the Digital Loan Application Optimization project.
- Investigate completion decline, upload failures, processing time, repeat uploads, session timeouts, mobile/web differences and technical bottlenecks.

Tables:
- applications.csv
- uploads.csv
- compliance_processing.csv
- system_events.csv

Important:
The data is intentionally constructed to contain realistic patterns that can be tested through analysis. Final conclusions should be derived from the data, not assumed in advance.
